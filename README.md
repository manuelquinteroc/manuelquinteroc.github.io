# manuelquinteroc.github.io

Personal website of Manuel Quintero Coronel, served by GitHub Pages.

- `index.html`: the whole site (About, Research, Experience, Teaching tabs)
- `assets/css/site.css`, `assets/js/site.js`: styles and tab behavior
- `files/`: CV and papers (PDFs)
- `images/`: profile photo, social preview, favicon
- The small folders (`research/`, `publication2/`, `cv/`, ...) only redirect old links.

To preview locally: `python3 -m http.server 8000`, then open http://localhost:8000.
To add a paper or news item, copy an existing block in `index.html` and edit it.
